# Бочка — учебная биржа

## Назначение

Небольшая биржа для практики 1: два участника торгуют акцией BOCH за рубли. Программа принимает лимитные и рыночные заявки, сопоставляет встречные заявки по цене, показывает стакан, остатки и статус заявок. Браузерный интерфейс работает через то же HTTP API. Данные живут в памяти и сбрасываются при перезапуске.

Это самостоятельная учебная версия сервиса [bochka-api](https://github.com/bochka-stock-exchange/bochka-api), подготовленная для структуры задания P1. Для запуска не нужны база данных, Docker, установка пакетов или интернет.

## Как запустить

Нужен Python 3.9 или новее. Из папки, где лежит этот README:

```bash
python3 src/main.py
```

На Windows используйте `py src/main.py`. Откройте **http://127.0.0.1:8000/**. Для остановки нажмите Ctrl+C.

На экране есть участники Алиса (`demo-alice`, 10 000 RUB) и Боб (`demo-bob`, 10 BOCH и 10 000 RUB). Переключатель участника позволяет посмотреть оба баланса и их заявки. Кнопка **«Показать демо-сделку»** создаёт продажу 2 BOCH по 100 RUB от Боба и рыночную покупку 1 BOCH от Алисы.

### Как проверить за минуту

1. Запустите команду выше и откройте страницу.
2. Нажмите **«Показать демо-сделку»**. Баланс Алисы станет **9 900 RUB и 1 BOCH**; в стакане останется продажа **1 BOCH по 100 RUB**.
3. Выберите **Боб**: его баланс будет **10 100 RUB и 8 BOCH**, заявка — «Исполнена частично».
4. Нажмите **«Отменить»** у заявки Боба: резерв 1 BOCH вернётся, баланс станет **9 BOCH**, стакан опустеет.

## Пример ввода и вывода

Через API можно повторить тот же сценарий. Команды выполняются в другом терминале после запуска сервера:

```bash
curl -s -X POST http://127.0.0.1:8000/api/orders \
  -H 'Authorization: TOKEN demo-bob' -H 'Content-Type: application/json' \
  -d '{"ticker":"BOCH","side":"SELL","qty":2,"price":100}'
```

Ответ содержит `"status": "NEW"`, `"filled": 0` и уникальный `id`. Затем:

```bash
curl -s -X POST http://127.0.0.1:8000/api/orders \
  -H 'Authorization: TOKEN demo-alice' -H 'Content-Type: application/json' \
  -d '{"ticker":"BOCH","side":"BUY","qty":1,"price":null}'
```

Ответ содержит `"status": "EXECUTED"` и `"filled": 1`. `GET /api/balances`, `GET /api/orders`, `GET /api/orders/{id}` требуют тот же заголовок; `GET /api/orderbook/BOCH` открыт всем. `DELETE /api/orders/{id}` отменяет собственную активную лимитную заявку и возвращает резерв.

Ошибочный ввод не меняет баланс и возвращает HTTP 400:

```bash
curl -i -X POST http://127.0.0.1:8000/api/orders \
  -H 'Authorization: TOKEN demo-alice' -H 'Content-Type: application/json' \
  -d '{"ticker":"BOCH","side":"BUY","qty":0,"price":100}'
```

Ответ: `{"error":"Количество должно быть целым числом от 1 до 100000"}`. Рыночная заявка без достаточного объёма во встречном стакане также возвращает 400; частичной рыночной сделки при этом не происходит.

## Как запустить тесты

```bash
python3 -m unittest discover -s tests -v
```

Тесты проверяют исполнение сделок, возврат резерва, улучшение цены, ошибочный ввод и HTTP API. Ожидаемый итог — `OK`.
